About

RELEASED

Every download checked on VirusTotal before it reaches your Downloads folder.

Your browser saves each download into a hidden quarantine folder. VirusTotal Quarantine locks it, looks it up on VirusTotal, and moves it to your Downloads folder if no antivirus engine flags it. Anything flagged waits for you, with its report a click away.

  • No window, no tray icon: everything happens in notifications
  • Sets up Chrome, Edge, Firefox, Safari, Brave and more by itself
  • Files stay locked until they're checked, and private files are never uploaded without asking
Runs on:
Windows 10/11, macOS, Linux
Written in:
Python
License:
MIT, free and open source

How it works

Clean:
no engine flags it, so it moves to Downloads with a short note.
Flagged:
stays locked in quarantine. Show report, then Delete or Mark as safe.
Unknown:
programs are uploaded for a scan. Documents and archives ask first, since uploads can be seen by VirusTotal's paying users.
Elsewhere:
saved somewhere else? Taken into quarantine at once, checked, and put back where you saved it.
Gaming:
while you play fullscreen, questions wait until you're done.

Guide

Click a topic to open it.

Before you start: get a free VirusTotal API key
  1. Sign up for a free VirusTotal account.
  2. Open your API key page and copy the key.
  3. VirusTotal Quarantine asks for it the first time it runs. Paste it there.
Install on Windows
  1. Click Download for Windows and open the file.
  2. If Edge holds it ("not commonly downloaded"): ... menu, then Keep, then Keep anyway.
  3. Paste your API key.

It brings its own Python and needs no administrator rights.

Install on macOS
  1. Click Download for macOS.
  2. Open VirusTotal Quarantine in your Downloads. It moves itself to Applications.
  3. The first time, macOS blocks it: click Done, then System Settings, Privacy & Security, Open Anyway (near the bottom), and enter your password.
  4. Paste your API key.
Install on Linux
  1. Download the package for your system and install it:
    • Ubuntu, Debian: .deb, then sudo apt install ./vt-quarantine-linux.deb
    • Fedora: .rpm, then sudo dnf install ./vt-quarantine-linux.rpm
    • Arch: .pkg.tar.zst, then sudo pacman -U vt-quarantine-linux.pkg.tar.zst
  2. Run vt-quarantine --install as yourself (not with sudo) and paste your API key.

Other distributions: download the source and run sh install.sh.

Your browsers

It points your browsers at the quarantine folder by itself and turns off downloads opening on their own. If a browser was open while it installed, restart that browser.

When a file is flagged
  1. The notification starts with Show report and Delete.
  2. After Show report, a third button appears: Mark as safe. The other two stay in place, so a quick click never lands on the wrong one.
  3. If 10 or more engines call it malicious, Mark as safe asks once more before letting it out.

A flagged file you let through isn't remembered: download it again and you get the warning again.

Downloads saved somewhere else

Open VirusTotal Quarantine again (Start menu, app menu or Applications), then Settings, to choose:

  • Move into quarantine (the default): checked, then put back where you saved it
  • Check only: looked up where they are, and only a flagged one brings a notification
  • Off: only the quarantine folder is checked
Updates

Once a day it checks for a new release and only installs one signed with the release key. On Windows and macOS it updates by itself. A Linux package asks first, because installing needs your password.

Uninstall
  • Windows: Settings, Apps, VirusTotal Quarantine, Uninstall
  • macOS: drag VirusTotal Quarantine to the Trash, or open Uninstall VirusTotal Quarantine and click Remove
  • Linux: vt-quarantine --uninstall, then remove the package

Your browsers get their download folder back. Files left in quarantine are unlocked, never deleted.
